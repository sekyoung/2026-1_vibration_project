# wing_multisine_model — Rebuild Guide

This document describes every block, parameter, and setting in `wing_multisine_model.slx`.
Use it to rebuild the model from scratch if the `.slx` is lost or corrupted.

---

## Purpose

Simulates the 2-DOF aeroelastic wing response to a multisine gust input.
Mirrors `multisine_analysis.m` in Simulink form:

- **Scope** — 3-axis time-domain view: `w_g`, `h`, `θ`
- **Spectrum Analyzer** — 3-channel frequency view of the same signals

---

## Required Files (same folder)

| File | Role |
|---|---|
| `wing_2dof.mat` | Source of `A`, `B`, `C_out`, `D_out` used to compute `Ad`, `Bd` |
| `multisine_function_generator.m` | Called by `InitFcn` before every simulation |

---

## Signal Flow

```
[From Workspace]
   wg_ts (dt=1/400)
        |
        +----------------------------> Scope port 1   (w_g)
        |                              SA    port 1   (w_g)
        v
[Discrete State-Space]
   Ad, Bd, C_out, D_out  dt=1/400
        |
        v
   [Demux]  (Outputs = 2)
     |          |
     v          v
 [Gain 1000]  [Gain 57.2958]
   h [mm]      theta [deg]
     |              |
     +-> Scope/2    +-> Scope/3
     +-> SA/2       +-> SA/3
```

---

## Block Parameters

### From Workspace — `wg_src`
| Parameter | Value |
|---|---|
| Variable name | `wg_ts` |
| Sample time | `0.0025` (= 1/400) |
| Output after final data value | `Extrapolation` (default) |

> `wg_ts` is a `timeseries` object generated by `multisine_function_generator()`.
> It is placed in the base workspace by the model `InitFcn` before each run.

---

### Discrete State-Space — `wing_ss`
| Parameter | Value |
|---|---|
| A | `Ad` — ZOH-discretised from continuous `A` at dt = 1/400 |
| B | `Bd` — ZOH-discretised from continuous `B` at dt = 1/400 |
| C | `C_out` = `[eye(2), zeros(2)]` |
| D | `zeros(2,1)` |
| Initial conditions | `[0; 0; 0; 0]` |
| Sample time | `0.0025` |

> Compute `Ad`, `Bd` in MATLAB:
> ```matlab
> load('wing_2dof.mat', 'A','B','C_out','D_out');
> sysd = c2d(ss(A, B, C_out, D_out), 1/400, 'zoh');
> Ad = sysd.A;  Bd = sysd.B;
> ```
> Then paste `mat2str(Ad)` and `mat2str(Bd)` into the block dialog.

|---|---|

### Gain — `h_mm`
| Parameter | Value |
|---|---|
| Gain | `1000` |
| Description | Converts plunge `h` from metres to millimetres |

---

### Gain — `th_deg`
| Parameter | Value |
|---|---|
| Gain | `57.29577951` (= 180/π) |
| Description | Converts pitch `θ` from radians to degrees |

---

### Scope — `scope`
Open block → **Settings** gear icon:

| Tab | Parameter | Value |
|---|---|---|
| Main | Number of input ports | `3` |
| Main | Layout | 3 rows × 1 column (default for 3 ports) |
| Display | Y-label (port 1) | `w_g [m/s]` *(optional)* |
| Display | Y-label (port 2) | `h [mm]` *(optional)* |
| Display | Y-label (port 3) | `theta [deg]` *(optional)* |

---

### Spectrum Analyzer — `SA`
Library: **DSP System Toolbox → Sinks → Spectrum Analyzer**

Connect the **same 3 signals** that feed the Scope:
- `wg_src` output → SA port 1
- `h_mm` output → SA port 2
- `th_deg` output → SA port 3

Open the SA window → **Settings** gear icon:

| Setting | Value |
|---|---|
| Number of input ports | `3` |
| Spectrum type | `Power` |
| Frequency scale | `Log` |
| Two-sided spectrum | Off (unchecked) |
| Sample rate (Hz) | `400` |

> **Tip:** keep the SA window open between runs. If it shows "No signal connected"
> before simulation starts, that is normal — it will populate once Play is pressed.

## Solver Settings
`Modeling` tab → **Model Settings** (`Ctrl+E`) → **Solver** pane:

| Parameter | Value |
|---|---|
| Type | Fixed-step |
| Solver | `ode4` (Runge-Kutta) |
| Fixed-step size | `0.0025` (= 1/400) |
| Stop time | `32` (= 8 periods × 4 s/period) |

---

## Model Callbacks (InitFcn)
`Modeling` tab → **Model Properties** → **Callbacks** tab → `InitFcn`:

```matlab
wg_ts = multisine_function_generator();
assignin('base', 'wg_ts', wg_ts);
```

This runs automatically before every simulation, ensuring `wg_ts` is always
fresh in the base workspace regardless of `clear` or workspace resets.
`multisine_function_generator.m` must be on the MATLAB path (same folder).

## Quick Rebuild Checklist

- [ ] New model: `new_system('wing_multisine_model')`
- [ ] Add `From Workspace` → set variable = `wg_ts`, sample time = `0.0025`
- [ ] Add `Discrete State-Space` → enter `Ad`, `Bd`, `C_out`, `D_out`, sample time = `0.0025`
- [ ] Add `Demux` (outputs = 2)
- [ ] Add `Gain` × 1000 (h_mm)
- [ ] Add `Gain` × 57.2958 (th_deg)
- [ ] Add `Scope` (3 input ports)
- [ ] Wire all connections per signal flow diagram above
- [ ] Set solver: Fixed-step, ode4, dt = 0.0025, stop = 32
- [ ] Set InitFcn callback (see above)
- [ ] Save model
- [ ] Manually add `Spectrum Analyzer` from DSP System Toolbox → Sinks and configure per table above
